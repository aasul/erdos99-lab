Recorded exact dependency versions and Python/platform details.

Implemented an epigraph problem in squared distances, analytic constraint gradients, and a coordinate gauge removing translation and rotation. Added structured and random starts, optional custom input, solver-status logging, and independent verification using exact rational squared distances.

For triangle avoidance, exact equality tests were rejected as scientifically uninformative: rounding alone would make almost every candidate look triangle-free. Implemented a positive scale-invariant margin instead. Fixed witness edges turn its disjunctive constraints into smooth branch problems. This is deliberately incomplete branch exploration; no global claim follows from the smallest result found.

## Failed and limited approaches

- Some SLSQP calls terminated unsuccessfully. All statuses and raw residuals are preserved; successful calls are not treated as proofs, and unsuccessful calls can still supply feasible repaired upper bounds. Aggregate counts are in `audit.json`.
- A single circular triangular-lattice patch is a poor model of every finite optimum. The 19-point comparison is a useful example of boundary effects.
- A zero numerical triangle count can come from perturbation, loose points or normalization. It is never used as evidence of exact optimality.
- The positive-margin problem explores selected witness branches only; a diameter gap is not a proved gap over all triangle-free configurations.
- Contact-bar rigidity alone omits longest-pair restrictions and treats inequalities as equalities. Both contact-only and combined rank diagnostics are supplied, without an optimality claim.
- Historical values are a useful check but not a current records database. Tiny apparent improvements are not new-record announcements.

## Verification and controls

Six focused tests check known benchmark geometry, analytic Jacobians by independent numerical differentiation, scale invariance and the triangle-detection trap, invalid inputs, deterministic seeds, and constrained optimization. Saved selected JSON files are reloaded with decimal parsing and reverified independently; all their pairwise distances are exported. Generated PNG and SVG plots for all selected configurations plus a full gallery, highlights, diameter comparison, starting-family scatter, and perturbation control. A rhombic-lattice control demonstrates an infinite triangle-free construction family whose fixed-angle density penalty prevents an asymptotic optimality claim.
